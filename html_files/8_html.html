Example 8: Motion Bounce

Instructions

  1. Press Run to start the balls moving across the circle.
  2. With sound off, the balls may appear to pass through each other.
  3. Turn Sound on — the click when the balls meet biases your perception toward seeing them bounce off each other.
  4. Use the sliders to tweak speed, ball size, rotation, color, and the number of pairs.
